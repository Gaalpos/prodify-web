# Atajos de teclado

<p class="lead">Los atajos que funcionan en Prodify en un ordenador. En teclados de estilo macOS, Ctrl sigue siendo Ctrl.</p>

## En cualquier sitio

| Atajo | Hace |
| --- | --- |
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Buscar en todo |
| <kbd>/</kbd> en la búsqueda | Ejecutar un comando |
| <kbd>Ctrl</kbd> <kbd>B</kbd> | Activar o desactivar la barra lateral automática |
| <kbd>Ctrl</kbd> <kbd>L</kbd> | Bloquear Prodify (si tiene contraseña) |

## En el editor de notas

| Atajo | Hace |
| --- | --- |
| <kbd>Ctrl</kbd> <kbd>E</kbd> | Cambiar entre Ver y Editar |
| <kbd>Ctrl</kbd> <kbd>B</kbd> | Negrita |
| <kbd>Ctrl</kbd> <kbd>I</kbd> | Cursiva |
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Enlace |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>X</kbd> | Tachado |
| <kbd>Ctrl</kbd> <kbd>Z</kbd> / <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>Z</kbd> | Deshacer / rehacer |
