# Notas

<p class="lead">Notas en Markdown con un editor cómodo, guardadas en un formato que entienden Obsidian y cualquier editor de texto.</p>

## Escribir

Las notas se abren en modo **Ver** o **Editar** (elige el predeterminado en Ajustes → Notas). <kbd>Ctrl</kbd> <kbd>E</kbd> cambia entre ellos. La barra de herramientas pone negrita, cursiva, títulos, listas, listas de verificación, enlaces y más, o puedes escribir Markdown directamente.

## Propiedades

Cada nota tiene propiedades arriba: **created**, **tags** y **categories**, y las que añadas tú. Se guardan como front matter YAML, con las categorías escritas como enlaces `"[[Nombre]]"`, igual que las guarda Obsidian.

## Encontrar notas

Las pestañas de arriba agrupan tus notas por **Categorías** y **Etiquetas**. Busca en la lista y ordénala por fecha de creación o A–Z.

## Panel o tarjetas

En **Panel**, la lista de notas queda a la izquierda y la nota abierta a la derecha. Arrastra la línea entre ambas para cambiar el ancho de la lista (doble clic para restablecerlo). En **Ajustes → Notas** puedes hacer que el lado de la nota solo aparezca al abrir una, para que la lista use todo el ancho. **Tarjetas** muestra todas las notas como tarjetas de distintas alturas, con un límite para que no sean demasiado altas.

## Plantillas y la nota de hoy

Las plantillas definen las propiedades y el texto con que empieza una nota nueva. **Nota de hoy** abre (o crea) una nota para el día actual.

## Archivo y papelera

Archiva las notas que quieres conservar pero no ver. Las notas borradas van primero a la **Papelera**, para que puedas recuperarlas.

## IA

Con la IA activada, el menú **IA** de una nota puede **Resumirla**, **Encontrar tareas** en ella y añadirlas a Tareas, o **Sugerir categorías**. Mira [IA y conexiones](../ai-connections/).
