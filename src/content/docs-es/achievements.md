# Logros

<p class="lead">Prodify se fija en lo que ya haces (leer, terminar tareas, mantener hábitos y aprender) y lo convierte en logros, XP y niveles.</p>

## Cómo funciona

No hay nada que configurar ni registrar aparte. Los logros se cuentan a partir de tus propios archivos cada vez que abres la página: termina un libro en Colecciones o marca una tarea, y su logro avanza.

Cada logro tiene seis **rangos**, y cada rango que desbloqueas da XP:

| Rango | XP |
| --- | --- |
| Bronce | 50 |
| Plata | 100 |
| Oro | 200 |
| Platino | 350 |
| Diamante | 550 |
| Leyenda | 800 |

Tu XP marca tu **nivel**. Cada nivel pide un poco más de XP que el anterior. Arriba de la página verás tu nivel, el XP que falta para el siguiente y cuántos rangos has desbloqueado. **Casi lo tienes** muestra los logros más cerca de su siguiente rango.

Aparece un mensaje cuando desbloqueas un rango nuevo.

## Los 20 logros

| Grupo | Logros |
| --- | --- |
| Colecciones | Ratón de biblioteca (libros leídos), Cinéfilo (películas vistas), Maratoniano (temporadas de series), Otaku (anime terminado), Jugón (juegos terminados), Coleccionista (elementos en tus colecciones) |
| Tareas y proyectos | Maestro de tareas (tareas hechas), Rematador (proyectos completados), Concentración profunda (horas de sesiones de concentración) |
| Hábitos | Constructor de hábitos (objetivos de hábitos cumplidos), Imparable (racha diaria más larga) |
| Diario y notas | Diarista (entradas), Consciente (registros de ánimo), Mente curiosa (preguntas diarias respondidas), Tomador de notas (notas escritas), Escritor (palabras en notas y diario) |
| Salud | Atleta (entrenamientos), Atento (días con meditación) |
| Aficiones y habilidades | Aficionado (sesiones de aficiones), Aprendiz eterno (niveles de habilidad ganados) |

Si desactivas una sección, sus logros también se ocultan.

## Privacidad

Todo se cuenta en tu dispositivo a partir de tus archivos. No se envía nada a ningún sitio y no hay clasificaciones.
