# Notes

<p class="lead">Markdown notes with a friendly editor, stored in a format Obsidian and every text editor understand.</p>

## Writing

Notes open in **View** or **Edit** mode (choose the default in Settings → Notes). <kbd>Ctrl</kbd> <kbd>E</kbd> switches between them. The toolbar handles bold, italic, headings, lists, checklists, links and more, or you can type Markdown directly.

## Properties

Each note has properties at the top: **created**, **tags** and **categories**, and any you add yourself. They're stored as YAML front matter, with categories written as `"[[Name]]"` links, the same way Obsidian stores them.

## Finding notes

The tabs across the top group your notes by **Categories** and **Tags**. Search the list, and sort it by date created or A–Z.

## Templates and Today's note

Templates set the properties and text a new note starts with. **Today's note** opens (or creates) a note for the current day.

## Archive and trash

Archive notes you want to keep but not see. Deleted notes go to **Trash** first, so you can bring them back.

## AI

With AI turned on, the **AI** menu on a note can **Summarize** it, **Find tasks** in it and add them to Tasks, or **Suggest categories**. See [AI and connections](../ai-connections/).
