# Tasks

<p class="lead">Write tasks the way you'd say them. Prodify works out the date, time, priority, list, project and repeat.</p>

## Adding tasks

Type a task and press Enter. While you type, a hint underneath shows what Prodify understood.

```text
Call mom friday 6pm !high #family +launch every week
```

| You type | Prodify sets |
| --- | --- |
| `today`, `tomorrow`, `friday`, `next week`, `in 3 days`, `2026-11-02` | Due date |
| `6pm`, `18:30`, `at 9` | Reminder time (and today or tomorrow if there's no date) |
| `!high`, `!medium`, `!low` (or `!!`, `!`) | Priority |
| `#listname` | List |
| `+project` | Project |
| `every day`, `weekdays`, `every week`, `monthly`, `yearly` | Repeat |

Spanish works too: `mañana`, `viernes`, `a las 9`, `cada semana`, `!alta`.

## Lists and smart lists

**Today** shows what's due today and overdue; **All** shows every open task. Create your own lists with a name, color and icon, and move tasks between them.

## Views

Every list can be shown three ways:

- **List**: a plain checklist, with subtasks under their task
- **Board**: columns by status, to drag tasks from to-do to doing to done
- **Matrix**: the Eisenhower matrix, sorting open tasks by important and urgent

## Subtasks, priorities and reminders

Open a task to add subtasks, a due date, a reminder, a priority, a list and a project. A reminder sends a notification at its time while Prodify is open.

## Repeating tasks

A task can repeat daily, on weekdays, weekly, monthly or yearly. Check it off and the next one appears with its date (and reminder) moved forward and its subtasks unticked.

## Focus sessions

From Home, **Focus session** lets you pick up to three tasks and start a timer. Finished sessions count toward Insights.

## In your files

All tasks live in `tasks.md`, one Markdown checklist line each. See [Your data folder](../data-folder/#tasks) for the format.
