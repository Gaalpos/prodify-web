# Keyboard shortcuts

<p class="lead">The shortcuts that work in Prodify on a computer. On macOS-style keyboards, Ctrl is still Ctrl.</p>

## Everywhere

| Shortcut | Does |
| --- | --- |
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Search everything |
| <kbd>/</kbd> in search | Run a command |
| <kbd>Ctrl</kbd> <kbd>B</kbd> | Auto-hide the sidebar on or off |
| <kbd>Ctrl</kbd> <kbd>L</kbd> | Lock Prodify (when it has a password) |

## In the note editor

| Shortcut | Does |
| --- | --- |
| <kbd>Ctrl</kbd> <kbd>E</kbd> | Switch between View and Edit |
| <kbd>Ctrl</kbd> <kbd>B</kbd> | Bold |
| <kbd>Ctrl</kbd> <kbd>I</kbd> | Italic |
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Link |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>X</kbd> | Strikethrough |
| <kbd>Ctrl</kbd> <kbd>Z</kbd> / <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>Z</kbd> | Undo / redo |
